# 정답성 실행 검증

스크래치패드에서 한다. 레포는 건드리지 않는다.

**기본은 1·6**(예제 실행, 손계산)이다. **심화 2~5**는 다음 중 하나일 때 한다: 로직이 단순하지 않다(구현이 길거나 그리디·DP 점화식 등 직접 증명이 필요하다), 제약 상한에서 시간·메모리가 아슬아슬해 보인다, 사용자가 요청했다.

1. **예제 실행**: 통과는 증거가 아니라 최소 조건이다.
2. **오라클**: 같은 폴더의 다른 풀이(`Main2` 등)를 서로의 오라클로 쓴다. 없으면 느려도 확실한 브루트포스를 짠다. 불가능하면 제약을 줄여 짠다. 정답이 여럿인 문제는 검사기를 쓴다.
3. **랜덤 대조**: 작은 입력을 대량 생성해 비교한다. 엣지(빈 입력, 원소 1개, 전부 같은 값, 음수, 최댓값, 경계 인덱스)를 포함한다. 불일치는 반례를 줄여서 보고한다.
4. **런타임 오류**: C++ `-fsanitize=address,undefined`, Java `-ea`로 예제와 랜덤 입력을 돌린다.
5. **최악 입력 시간**: 제약 상한 크기로 병목이 될 구조(전부 같은 값, 정렬된 입력, 일직선 트리·그래프)를 만들어 잰다. 로컬 시간은 채점기와 다르므로 제한 시간의 몇 배인지로 판단하고 단정하지 않는다.
6. **손계산**: 시간복잡도(중첩 곱, 재귀 분기·깊이, 반복 복사)와 값 상한을 `int`/`long` 범위와 대조한다.

## 공용 도구: `scripts/run_samples.sh`

풀이 폴더의 모든 풀이를 같은 입력으로 컴파일·실행해 출력(토큰 단위, 공백·개행 차이 무시)과 시간을 비교한다. 직접 짠 임시 하네스보다 이것을 먼저 쓴다.

```
bash .claude/skills/ps-audit/scripts/run_samples.sh <풀이 폴더> <입력 파일> [기대 출력 파일]
```

- 기대 출력 파일이 없으면 처음 성공한 풀이(파일명 순)가 기준이고 나머지를 그것과 비교한다. 앞 풀이가 컴파일 실패·런타임 오류면 기준이 다음 풀이로 넘어가므로, 기준 풀이가 맞는지는 별도로 확인한다. 있으면 모든 풀이를 기대 출력과 비교한다.
- 컴파일 옵션은 `ps_check.py`와 같다 (C++ `g++-16 -std=c++20|c++23 -O2 -Wall -Wextra`, Java `javac --release 21`, Python `python3 -B`). `Main2.java`처럼 클래스명이 다른 파일도 처리하고 `package` 줄은 지운 복사본으로 컴파일한다.
- 환경변수: `SAN=1`(C++ ASan+UBSan, 오류 시 중단, Java `-ea`), `FPOFF=1`(`-ffp-contract=off`), `TL=<초>`(풀이당 제한 시간, 기본 10), `WORK=<디렉터리>`(작업 위치, 스크래치패드 권장). 레포에는 아무것도 쓰지 않는다.
- 결과 열: 기준 / 일치 / 불일치(첫 차이 한 줄) / 컴파일실패 / 런타임오류(종료 코드, 첫 오류 줄·신호) / 시간초과 / 건너뜀(`main`이 없는 함수형 풀이). `SAN=1`이면 UB·범위 초과도 런타임오류로 잡힌다.
- 입력·기대 출력은 일반 파일이어야 한다 (`<(...)` 프로세스 치환은 안 된다). 종료 코드는 모두 통과 0, 불일치·컴파일 실패·런타임 오류·시간 초과 1, 인자 오류·풀이 파일 없음 2.
- 한 번에 한 입력만 돈다. 랜덤 대조는 입력 생성기와 이 스크립트를 `bash` 루프로 엮는다.

## 환경 함정 (이 환경에서 실제로 겪은 것)

- **셸**: 드라이버·루프는 `bash` 스크립트 파일로 만들어 `bash 파일`로 돌린다. 명령줄에서도 zsh를 가정하지 않는다.
  - zsh는 변수를 단어 분리하지 않는다. 경로 여러 개는 배열(`P=(a b); cmd "${P[@]}"`)로 넘기거나 직접 적는다.
  - zsh에서 `=`로 시작하는 단어(`echo ====`)는 명령 치환으로 해석돼 에러가 난다. 구분선은 `echo -----`을 쓴다.
  - zsh의 `echo '...\n'`은 개행으로 바뀌어 소스가 깨진다. 소스 조각은 `cat <<'E'`나 `printf`로 쓴다.
  - `printf`에 `-`로 시작하는 값을 넘길 때는 `printf -- "$값"`으로 쓴다 (옵션으로 읽힌다).
- **부동소수점**: 이 맥은 arm64라 `-O2`에서 FMA 융합으로 경계 값이 달라질 수 있다 (`2756`에서 실제로 `200 to 300`과 `220 to 300`이 갈렸다). 실수 비교·경계가 걸린 문제는 `FPOFF=1`로도 돌려 결과가 다르면 "로컬 환경 차이, 채점기 영향 미확인"으로 보고한다.
- **Java**: 시간·메모리는 `/usr/bin/time -p`(`real`)와 `/usr/bin/time -l`(최대 RSS, macOS)로 잰다. JVM 시작이 0.02초 안팎이라 작은 입력의 시간 비교는 의미가 없다.
- **BOJ 원문**: 백업 JSON의 `limit` 필드는 비어 있다. 시간·메모리는 `info`(`time_limit`, `memory_limit`)에 있고 "하단 참고"의 추가 조건 문구는 백업에 없다. 그 부분은 미확인으로 쓴다.
- **로컬 시간**은 채점기와 다르므로 제한의 몇 배인지로만 판단한다.
- 함수형 문제(프로그래머스·LeetCode)는 `solution`(또는 주어진 시그니처)을 호출하는 짧은 드라이버를 스크래치패드에 만들어 돌린다. 만들 수 없으면 실행 검증을 하지 않았다고 밝힌다.
- 끝나면 `__pycache__`를 지운다 (`find .claude -name __pycache__ -exec rm -rf {} +`).
